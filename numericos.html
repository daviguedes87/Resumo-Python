Dados do Tipo Numérico

Assim como na matemática, na programação temos diferentes tipos de números: inteiros, decimais, imaginários e outros.

No Python, existem 3 tipos numéricos principais. É essencial saber quando usá-los para evitar erros de precisão ou de lógica nos seus cálculos.

Tipos de dados numéricos:

  • Integer (int):

    Representa números inteiros, ou seja, números sem casas decimais.

    
number = 5
print(type(number))
    <class 'int'>
  • Floating Point (float):

    Representa números reais ou "ponto flutuante". São os números que possuem casas decimais.

    💡 Atenção: No Python, usamos ponto (.) e não vírgula para separar as casas decimais.

    
number = 5.5555
print(type(number))
    <class 'float'>
  • Complex (complex):

    Usados para representar números complexos com a unidade imaginária j.

    
number = 5 + 8j
print(type(number))
    <class 'complex'>

Resumo

O int é para contagens exatas, o float para preços ou medições, e o complex para cálculos científicos avançados.
