Sintaxe do Python

Para você entender o Python, é fundamental entender o que é sintaxe.

Sintaxe na Língua Portuguesa

É a parte da gramática que estuda a disposição e a relação das palavras. Ela determina como os elementos (sujeito, predicado, etc.) se organizam para criar frases com sentido.

Sintaxe no Python

No Python, a indentação (o espaço no início da linha) faz parte da lógica do código! Além disso, seguimos as regras definidas pelo criador da linguagem, Guido van Rossum.

Declarações no Python

Um programa de computador recebe uma lista de "instruções". No Python, a forma mais básica de dar uma instrução para exibir informação é usando a função print().

Exemplo de uso do Print:


print("Hello, world!")
  • Resultado: A mensagem dentro dos parênteses se torna visível para o usuário no console.

⚠️ Atenção às Aspas!

Para escrever mensagens (strings), você pode usar aspas duplas (" ") ou simples (' '), mas deve manter o padrão:

  • ✅ print("Texto") - Correto
  • ✅ print('Texto') - Correto
  • ❌ print("Texto') - Erro! Não misture aspas diferentes.

✔ Código Corrigido:


if 5 > 2:
    print("Espaço de 4 campos")
    print("Espaço de 6 campos") # Agora sim!
