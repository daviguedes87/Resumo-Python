O que é a identação de um código?

A indentação refere-se aos espaços no início de uma linha de código.

Enquanto em outras linguagens a indentação serve apenas para facilitar a leitura (estética), em Python ela é obrigatória. O Python usa a indentação para indicar onde começa e onde termina um bloco de código.

Como usar a identação no Python

Em linguagens como JavaScript, usamos chaves {} para abrir blocos. No Python, usamos os dois pontos ( : ) e o recuo da linha.

Exemplo Correto:


if 5 > 2:
    print("O número 5 é maior que o número 2!")
O número 5 é maior que o número 2!

Exemplo de Erro (O que NÃO fazer):


if 5 > 2:
    print("Espaço de 4 campos")
      print("Espaço de 6 campos") # ERRO!

✔ Código Corrigido:


if 5 > 2:
    print("Espaço de 4 campos")
    print("Espaço de 6 campos") # Agora sim!

Dica: Para facilitar, use sempre a tecla TAB do seu teclado para identar!
