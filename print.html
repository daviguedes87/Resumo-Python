Uso do Print no Python

Como já dito no módulo de sintaxe, o print é a forma de declaração mais básica que temos no Python.

Chamamos essa declaração de Função. O Python possui várias funções (functions) e o print() é a porta de entrada para todas elas.

O que é uma Função Nativa?

O print() é uma função nativa (ou built-in function). Isso significa que ela já vem "instalada" no núcleo do Python; não precisamos importar bibliotecas externas para usá-la.

Mas o que caracteriza uma função?

  • O uso dos parênteses (): Eles servem para "chamar" a função para executar uma tarefa.
  • Aceita argumentos: Argumentos são os dados que você coloca dentro dos parênteses para a função processar.

Exemplo de Uso e Argumentos

No exemplo abaixo, as frases e variáveis dentro dos parênteses são os argumentos que o print vai exibir no console:


# O argumento aqui é uma String direta
print("Olá, bem-vindo à Escola Python!")

nome = "Davi"
# Aqui passamos dois argumentos: uma String e uma Variável
print("Usuário logado:", nome)
Olá, bem-vindo à Escola Python!
Usuário logado: Davi
