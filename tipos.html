Tipos de dados de uma Variável

Agora que você já sabe o que são as variáveis, é fundamental conhecer os tipos existentes no Python!

Como vimos, as variáveis são caixas, e cada caixa no Python é feita para armazenar um tipo de dado específico (texto, números, listas, etc).

Principais tipos de dados

  • Tipo de texto: str (String)
  • Tipos numéricos: int, float, complex
  • Tipos de sequência: list, tuple, range
  • Tipo de mapeamento: dict (Dicionário)
  • Tipos de conjuntos: set, frozenset
  • Tipo booleano: bool (True ou False)
  • Tipos binários: bytes, bytearray
  • Nenhum tipo: NoneType

Importância dos tipos de dados

O computador entende estritamente o que você escreve. Se você tentar misturar tipos incompatíveis, ele não saberá o que fazer.

Situação hipotética: Tentar somar uma "letra" com um "número". Se na vida real não somamos letras com números, na programação isso gera um conflito de lógica.

Exemplo do que NÃO fazer:

nome = "Cristiano Ronaldo"
numero = 5

# Isso vai gerar um erro de tipo (TypeError)
soma = nome + numero

Erro no console: TypeError: can only concatenate str (not "int") to str

Isso acontece porque você não pode "grudar" (concatenar) uma palavra com um número inteiro diretamente.
