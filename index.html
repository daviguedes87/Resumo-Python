A História do Python

1. O Início (Final dos anos 80)

Tudo começou em dezembro de 1989, na Holanda. Guido van Rossum, o criador da linguagem, queria um projeto para ocupar seu tempo durante as férias de Natal. Ele decidiu escrever um interpretador para uma linguagem que fosse sucessora da linguagem ABC, focando em lidar com exceções e interagir com o sistema operacional Amoeba.

2. Por que "Python"?

Não tem nada a ver com a cobra! Guido era fã do grupo de comédia britânico Monty Python's Flying Circus. Ele queria um nome curto, único e misterioso. Até hoje, exemplos clássicos de Python usam "Spam" e "Eggs" em referência aos esquetes do grupo.

3. Marcos Importantes

  • 🚀 1991 (v0.9.0): Primeiro código publicado. Já tinha classes e herança.
  • 🛠️ 1994 (v1.0): Introdução de ferramentas funcionais (lambda, map, filter).
  • 📈 2000 (v2.0): Chegada das list comprehensions e novo sistema de memória.
  • ✨ 2008 (v3.0): A grande mudança para tornar a linguagem mais limpa e moderna.

4. Filosofia: O Zen do Python

O Python é guiado pela PEP 20. Se você digitar import this no terminal, verá as regras de ouro da linguagem:

  • Bonito é melhor que feio.
  • Explícito é melhor que implícito.
  • Simples é melhor que complexo.
  • Legibilidade conta.

5. Python Hoje

Mantido pela Python Software Foundation (PSF), é a espinha dorsal de gigantes como Google, Netflix e NASA. Sua simplicidade a tornou a favorita para Inteligência Artificial, Ciência de Dados e Desenvolvimento Web.
