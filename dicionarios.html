Dicionários no Python

No Python, os dicionários são coleções de dados muito poderosas baseadas em pares de chave e valor.

Analogia com a Língua Portuguesa

O dicionário tradicional é uma obra que compila vocábulos e seus significados. No Python funciona da mesma forma:

  • Chave (Key): Seria a palavra que você está procurando.
  • Valor (Value): Seria o significado ou conteúdo daquela palavra.

Como criar um dicionário no Python?

Há duas maneiras principais de se construir um dicionário:

1. Usando Chaves { }

Atribuímos pares "chave": "valor".


dicionario = {"nome": "cristiano", "gols": 900}
print(dicionario)
{'nome': 'cristiano', 'gols': 900}

2. Usando o método dict()


metodo_dict = dict(nome="davi", idade=25, profissao="dev")
print(metodo_dict)
{'nome': 'davi', 'idade': 25, 'profissao': 'dev'}

⚠️ Atenção à Sintaxe do dict()

No método dict(), as chaves não usam aspas e usamos o sinal de igual (=).

Acessando os Itens do Dicionário

Acessando um valor específico

Usamos o nome da chave dentro de colchetes [ ] para buscar o dado.


jogador = {
    "nome": "cristiano",
    "camisa": "7",
    "N_gols": 970
}

x = jogador["nome"]
print(x)
cristiano

Como descobrir as chaves?

O método .keys() retorna uma lista com todas as chaves disponíveis.


x = jogador.keys()
print(x)
dict_keys(['nome', 'camisa', 'N_gols'])
