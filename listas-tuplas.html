Uso das Listas, Tuplas e do Range no Python

Só por ter nomes diferentes você já percebe que são coisas diferentes e têm usos diferentes. Irei explicar um a um, fique tranquilo!

1. Listas (Arrays)

Pense numa lista como se fosse um armário com várias gavetas, e cada gaveta tem o seu número. Você sabe que em uma gaveta podemos guardar o que quisermos.

Para criar uma lista, basta usar os colchetes [ ]:


# Lista vazia e lista com itens
gavetas = []
lista_frutas = ["banana", "maca", "abacate", "uva"]
print(lista_frutas)
['banana', 'maca', 'abacate', 'uva']

Os elementos são separados por vírgulas. Para operações detalhadas, acesse a aba "Carac. Listas" no menu.

2. Tuplas

Se a Lista é um armário aberto, a Tupla é um cofre trancado: ela é imutável.

Usamos parênteses ( ) para criar uma tupla. Tentar alterar um valor nela gera um erro de sistema:


dias_semana = ("Domingo", "Segunda", "Terça")

# Isso vai travar o código:
dias_semana[0] = "Feriado"
TypeError: 'tuple' object does not support item assignment

3. Range

O range() funciona como um contador automático.

Ele gera uma sequência de números. Lembre-se: na computação começamos do 0, então ele para um número antes do limite definido:


# Gerando números de 0 até 4 (para antes do 5)
sequencia = range(5)

print(list(sequencia))
[0, 1, 2, 3, 4]

Resumo da Ópera

Tipo Símbolo Uso Principal
Lista [] Dados que podem mudar.
Tupla () Dados fixos (segurança).
Range range() Gerar contagens numéricas.
