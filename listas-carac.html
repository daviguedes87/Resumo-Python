Trabalhando com Listas no Python

Listas são usadas para armazenar vários itens em uma única variável.

1. Índices e Fatiamento (Slicing)


frutas = ["banana", "maca", "pera"]
print(frutas[0])
banana

Pegando Intervalos (Slicing)


print(frutas[0:3])
['banana', 'maca', 'pera']

2. Modificando Elementos


frutas[0] = "abacate"
print(frutas)
['abacate', 'maca', 'pera']

3. Adicionando Itens

Método .append()


frutas.append("caju")
['abacate', 'maca', 'pera', 'caju']

Método .insert()


frutas.insert(2, "uva")
['abacate', 'maca', 'uva', 'pera', 'caju']

4. Removendo Itens

Método .remove()


frutas.remove("abacate")
['uva', 'pera', 'caju']

Método .pop()


frutas.pop(1)
['uva', 'caju']
