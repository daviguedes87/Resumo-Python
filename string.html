Tipo de dado: String (str)

A palavra "string" significa corda ou cordão, mas para facilitar, pense em uma corrente.

Uma corrente de portão é composta por vários elos. O Python entende a String exatamente assim: uma corrente onde cada "elo" é uma letra ou caractere.

Exemplo prático:

nome = "Cristiano"
  • nome: É a nossa variável (a etiqueta da caixa).
  • "Cristiano": É a nossa string. Ela é identificada pelo uso de aspas (simples ou duplas).

⚠️ Como o Python enxerga a String

O Python vê a palavra como um conjunto de elementos organizados em uma lista. Cada letra recebe um número de posição (índice), começando sempre pelo ZERO.

Mapa de Índices (A Corrente):

Letra C r i s t i a n o
Índice 0 1 2 3 4 5 6 7 8

Verificando o Tipo no Console

Sempre que você perguntar ao Python o tipo de uma variável de texto, ele retornará str.

nome = "Cristiano"
print(type(nome))
<class 'str'>

O termo class 'str' indica que a variável pertence à classe das strings (textos).
