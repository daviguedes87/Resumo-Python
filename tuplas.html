Tuplas no Python

As Tuplas são coleções similares às listas, mas com uma característica fundamental: são imutáveis.

Isso significa que, após a sua criação, não podemos mudar os valores dos elementos, nem adicionar ou remover itens diretamente.

Como criar uma Tupla

1. Usando Parênteses ()

As tuplas são identificadas pelo uso de parênteses após o nome da variável.

Exemplo_de_Tupla = ('elemento1', 'elemento2')

2. Usando o método tuple()

Assim como nas listas, podemos usar o construtor oficial.

metodo_tuple = tuple(('banana', 'maca', 'pera'))

E se eu precisar alterar uma Tupla?

Como a tupla é imutável, o truque é transformá-la temporariamente em uma Lista, fazer a alteração e depois transformá-la em Tupla novamente.

Exemplo de Adição por Conversão:

# 1. Nossa tupla original
ex_tupla = ('elemento1', 'elemento2')

# 2. Convertendo para lista
lista_temp = list(ex_tupla)

# 3. Adicionando o novo item
lista_temp.append('elemento3')

# 4. Convertendo de volta para tupla
ex_tupla = tuple(lista_temp)

print(ex_tupla) # ('elemento1', 'elemento2', 'elemento3')

Adicionando uma tupla a outra

Você também pode "somar" duas tuplas. O Python criará uma nova tupla contendo os elementos de ambas.

tupla1 = ('elemento1', 'elemento2')
tupla2 = ('elemento4',) # Nota: a vírgula é necessária para tuplas de um item
tupla1 += tupla2

print(tupla1) # ('elemento1', 'elemento2', 'elemento4')

💡 Dica de Mestre

Essa liberdade de converter tipos permite que você faça qualquer coisa: deletar elementos, ordenar ou limpar a coleção. Lembre-se apenas que a tupla final sempre será "fechada" para mudanças diretas.
